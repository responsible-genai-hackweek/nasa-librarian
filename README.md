# nasa-librarian

*Context: 2i2c*

## Overview
A reference desk for NASA Earth data. It interviews you, finds what fits, hands you
code that runs — and says plainly when nothing in the holdings answers your question
at the scale asked.

Started at the Responsible Generative AI workshop, UW eScience Institute, August 2026.
